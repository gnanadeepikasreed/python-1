University Scholarship Allocation
Overview
Evaluates scholarship applicants using academic performance, subject-wise minimum marks, attendance, and income criteria. Eligible applicants are ranked using predefined tie-breaking rules.
Features
Accepts applicant details
Checks scholarship eligibility criteria
Identifies eligible applicants
Ranks eligible applicants using tie-breaking rules
Displays applicant results
Technologies Used
Python 3
Python standard input/output
No external libraries required
Concepts Demonstrated
variables, data types, operators, conditional statements, loops, lists, tuples, and sorting/ranking logic.
How to Run
Install Python 3.
Open a terminal in the project folder.
Run:
```bash
python scholarship_allocation.py
```
Follow the prompts and enter the requested information.
Project File
`scholarship_allocation.py`
Notes
This is an educational console-based Python project. Enter values in the format requested by the program. Any exchange rates or fee percentages used by the program are sample values where applicable.
